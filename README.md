# 兵子装修台

记录装修过程中的每一步花销。数据保存在浏览器本地（localStorage），不上传到服务器。

## 功能

- **记账（账单）**：所有分类的支出统一在账单里记账，按分类分组展示、占比条、总支出汇总，可随时编辑/删除
- **工作台**：瓦工 / 木工 / 油工 / 安装 / 全屋定制 / 电器 / 家具 / 零散花销 8 个方向改为记录工作流程——完成打勾划线，每项可记录衔接的下一步流程（支持多级嵌套），任意流程可独立删除，删除后其下衔接流程自动顶替位置
- **设计板块**：施工图纸、灵感墙（图片 / 链接 / 点子，点子可记录文字与配图，全屏看图 + 标记标注）
- **PWA**：支持添加到手机主屏幕、全屏独立运行、离线可用（Service Worker 缓存）
- 数据本地存储，无需账号，可离线使用

## 技术栈

纯静态页面（HTML + CSS + JavaScript），无构建步骤，可直接部署到任意静态托管。

## 本地预览

直接双击 `index.html` 会跳转到手机预览页（`手机预览.html`），可切换手机 / 全屏视口查看排版。

## 部署

推送到 GitHub 仓库后，在仓库 Settings → Pages 中开启（Deploy from branch，分支 `main`，目录 `/`）即可免费上线。
